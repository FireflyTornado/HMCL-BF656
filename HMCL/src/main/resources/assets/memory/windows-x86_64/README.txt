Windows 10/11 x64. HMCL invokes --clean --profile safe/default/full according to the user-selected profile.
The enable setting defaults to off; the profile defaults to safe. RAM ranges in the UI are guidance, not technical requirements.
No automatic update is configured. Rebuild and update the version, source archive and pinned SHA256 together.
